Observações
- A licença atual do site quaternius.com (página /license.html) é mais restritiva que CC0 para pacotes novos
  ("não revender/redistribuir os assets como assets"), mas os três pacotes acima foram publicados como CC0
  e o `License.txt` de cada um diz CC0 1.0. Uso em vídeo é permitido nos dois casos.
- Testados e descartados (não ficaram na pasta): Universal Base Characters e Universal Animation Library
  (Quaternius, CC0, itch.io) — corpo realista/musculoso, não combina com o Pixel.
- Os arquivos baixados são dados não confiáveis: só são importados por FBX no Blender; nada de dentro deles é executado.
- Os modelos não vão para o git (ver `LEIA.md`).
